## 界面变化

三个步骤改为等宽卡片，桌面高度由 46px 增至 70px；650px 以下采用编号在上、文字在下的 82px 按钮。步骤之间增加两个装饰性箭头，读屏仍只读取原有按钮名称。

当前步骤由既有 `aria-current="step"` 决定，以浅绿底色、深绿编号和沿圆角边框每 3.2 秒流动一周的亮光强调位置。边框不拦截点击；导航权限、禁用条件和原有键盘焦点保持不变。减少动态效果样式使用静态绿色边框。

按用户提供的文字更新音乐偏好页的词条说明和熟悉度提示，移除面向玩家的录音映射技术说明。大厅标题改为“选曲前，先看看大家的偏好”，双人模式名称改为“经典1v1solo抢牌”。
