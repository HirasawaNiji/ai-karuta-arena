# 艺人专场：周杰伦全曲库玩法

任务：[Issue #12](https://github.com/HirasawaNiji/ai-karuta-arena/issues/12)。

2026-09-24 用户新增方向：支持周杰伦专场，并以全曲库为内容目标。复用既有画像、公平检查、禁歌、1v1/多人流程；不硬编码文化/语言偏好，不接大模型。

## 可执行范围

- 房主可选“周杰伦专场”，由明确 ArtistId 和可审查的曲目清单限定候选；艺人别名、合作歌曲的纳入规则由清单显式记录，不能仅做名称包含匹配。
- 先按艺人/模式过滤，再按可播放录音、片段和卡牌核验可用性；随后走既有熟悉度矩阵、逐首补缺和公平检查。禁歌、曲库不足、旧确认失效规则保持不变。
- 玩家可选熟悉歌曲或跳过；使用 score-v2-manual 的识别范围，不能因为参与周杰伦专场就视作所有歌熟悉。
- 卡牌默认可用歌名文字卡，图片/官方卡牌是可替换展示资源。对经典 1v1 仍按 D0 核对结果适配其真实卡面格式；不提前承诺文字卡已接通引擎。
- 清单包含歌曲、艺人、收录范围、版本/合作信息、来源、核对日期；音源另记录音、片段、使用依据和可用状态。展示总收录数、可玩数、缺失/待核验数。
- “全曲库”是待核对的目标。完整性尚未验证时界面标明“周杰伦专场（部分曲目）”，不把少量样例或元数据清单称为完整可播库。

用户提及 QQ 音乐版权安排作为选题背景；该信息本轮未独立核实，不作为下载、分发或调用平台接口的授权依据。官方卡牌范围仍未知，保留 pending 状态；已明确授权的 karuta-web 内容可按实际可用性纳入。缺少 QQ Key 或官方卡牌不能阻塞手动画像和合法可用素材的专场演示。

## 依赖和验收

依赖 #4 核心 Mock、D0 的引擎/素材核对及 D1 的真实房间与手动画像，再做专场可玩切片。M1 仅提供开放 ArtistId、录音/题目/卡牌与使用依据契约，本轮不伪造全曲库或音频。

验收：非目标艺人不会入选；合作/版本映射可核对；不可用资源被排除且有原因；部分曲库诚实标识；短库/低覆盖暂停并由房主选择；无 QQ/LLM Key 也可基于已核验素材完成真人一局。两人/多人分别沿用其规则，不改变胜负判定。
