# Demo 音乐偏好分组标签

对应 Issue #63，延续 PR #62 的导航和偏好文案。此次只完成标签配置、分组展示及保存验证；每标签 30 首的正式歌单和按标签联动筛歌留待后续。

后续候选选曲见 [Demo 歌单审阅稿](playlists/demo-candidates.md)（Issue #65）：沿用这里的 16 个标签与分组，提供每标签 30 首已核验网易云歌曲／专辑条目的推荐。该清单用于审阅，接入音频与标签联动筛歌仍待后续实施。

## 标签与展示

| 分组 | 标签 |
| --- | --- |
| 语言 | 国语、粤语、日语、英语、韩语 |
| 曲风 | 流行、摇滚、电子、民谣、说唱、R&B、国风／古风 |
| 内容与文化 | 动漫、游戏、虚拟歌手、影视 |

服务端目录使用 `onboarding-tags-v2`，共 16 个展示标签，另保留不向玩家展示的 `lang:unknown`。国语沿用已有 `lang:zh` ID；新增粤语使用 `lang:yue`。内容与文化的四个标签登记在 `cultures` 维度，前端从服务端目录读取标签，不另存一份标签名称。

页面按维度分组，采用浅色分组卡片、胶囊按钮和分组已选数量；选中项显示绿色勾选，支持跨组多选和再次取消。按钮保留 `aria-pressed`、键盘焦点和至少 44px 高度。未来目录加入年代或地区时显示“更多偏好”，空分组不显示。

歌曲语种、曲风及录音版本仍需逐曲核对。本次不为 PJSK 占位歌曲批量推断标签，不声称选中标签已经联动过滤下方曲库。
