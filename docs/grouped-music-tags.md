# Demo 音乐偏好分组标签

标签基础对应 Issue #63，延续 PR #62 的导航和偏好文案；按标签随机展示熟悉歌曲及换批对应 Issue #69，见下文。

候选选曲见 [Demo 歌单审阅稿](playlists/demo-candidates.md)（Issue #65）：沿用这里的 16 个标签与分组，提供每标签 30 首已核验网易云歌曲／专辑条目的推荐。PR #68 已提供 351 首音源的运行时接入与标签映射，部署与核验边界见 [公网前奏部署](public-intro-deployment.md)。

## 标签与展示

| 分组 | 标签 |
| --- | --- |
| 语言 | 国语、粤语、日语、英语、韩语 |
| 曲风 | 流行、摇滚、电子、民谣、说唱、R&B、国风／古风 |
| 内容与文化 | 动漫、游戏、虚拟歌手、影视 |

服务端目录使用 `onboarding-tags-v2`，共 16 个展示标签，另保留不向玩家展示的 `lang:unknown`。国语沿用已有 `lang:zh` ID；新增粤语使用 `lang:yue`。内容与文化的四个标签登记在 `cultures` 维度，前端从服务端目录读取标签，不另存一份标签名称。

页面按维度分组，采用浅色分组卡片、胶囊按钮和分组已选数量；选中项显示绿色勾选，支持跨组多选和再次取消。按钮保留 `aria-pressed`、键盘焦点和至少 44px 高度。未来目录加入年代或地区时显示“更多偏好”，空分组不显示。

原标签基础改动没有为 PJSK 占位歌曲批量推断标签；下方歌曲匹配使用当前服务端目录的实际标签，不根据歌名猜测归类。

## 2026-10-05：熟悉歌曲按标签随机展示

- “挑几首熟悉的歌”初次展示从全曲库随机抽取 5 首，单批不重复。
- 选择标签后，从匹配任一已选标签的歌曲并集中随机抽取 5 首；不是每个标签各抽 5 首，也不要求一首歌同时符合所有标签。取消全部标签恢复全曲库抽取。
- 标题旁提供“再换一批”。候选足够时避开上一批；不足以全部换新时优先展示上一批未出现的歌曲，再补足。候选不足 5 首时全部展示；无匹配时提示换标签或搜索，不混入其他标签歌曲。
- 搜索仍覆盖全曲库，最多展示 30 个结果；清空搜索回到当前随机批次。点击标签或“再换一批”会清空搜索并展示对应候选。
- 熟悉度记录独立保存于列表之外，换批、标签变化和搜索不会清除已填写值；选择熟悉度也不会触发重新抽取。保存、刷新和重新进入偏好页沿用原有画像恢复流程。
- 本功能只影响画像录入时展示的候选，不改变正式对局选曲、公平评估、题序或音频规则。

浏览器回归见 `tests/browser/song-suggestions.spec.mjs`：以明确的测试目录验证全库/单标签/多标签、空与短候选、换批、搜索、熟悉度保存恢复和手机/桌面布局。已有画像生命周期回归改为搜索指定歌曲，避免依赖旧列表固定前 30 首的顺序。

本轮实测：静音 Chrome 的上述两项浏览器回归 2/2 通过；360/390/430px 与 1280px 均无横向溢出，换批按钮至少 44px 高，360px 截图已目视核对。核心 588/588、构建、类型、lint、仓库及 diff 检查通过。浏览器使用明确的测试目录，本轮未进行音频播放、完整对局或 QQ 真机验收。
